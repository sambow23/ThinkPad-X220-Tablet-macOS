| RAM | 8GB 1333MHz DDR3 |

## Hardware compatibility

#### What works
- CPU power management
- GPU acceleration and video codecs
- SSD (SATA)
- Wi-Fi (itlwm) (custom fork)
- Bluetooth (including AirPods audio)
- All USB ports
- Trackpad
- TrackPoint
- Tablet Input (with Pen Pressure) | (needs custom software)
- Touchscreen Input (with Magic Trackpad Gestures) | (needs custom software)
- FN Keys
- Screen Brightness
- Battery percentage
- Sleep
- DisplayPort Out
- Internal Audio (Speakers, Headphones)
- Ethernet
- Tablet Buttons (needs custom software)

#### Untested
- iCloud Services
- Webcam
- VGA Out
- ExpressCard (probably works)
- SD Card Slot
- Microphone

#### Not working
- Nothing :)
